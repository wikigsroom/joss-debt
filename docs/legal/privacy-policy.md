# 《香火债》隐私政策

更新日期：2026-10-11  
生效日期：2026-10-11  
政策版本：1.4

适用范围：Windows 与 Android 客户端 0.3.0 的离线模式和可选对灯联机模式，以及本隐私政策展示网页；旧版离线客户端请参阅历史政策

## 温馨提示

1. 《香火债》可离线单人游玩，也提供由您主动连接的双人对灯模式。无需手机号或实名注册。Android 0.3.0 申请联网和振动普通权限；离线模式不会自动上传愿簿、成就或单人进度。

2. 首次连接每个服务器前，游戏说明信息处理范围并由您确认。对灯会向您选择的服务器发送匿名联机身份、昵称、配装、房间及操作信息，用于匹配、对战裁定、断线恢复和战绩。对手可看到昵称、配装及对局状态；请勿填写真实身份信息。

3. 游戏会在本机保存愿簿、设置、角色成长、成就、单局进度及本地游玩日志。愿名由您自愿填写，请使用不包含真实姓名、联系方式或其他隐私的昵称。

4. 存档导出、复制传递文字、从剪贴板粘贴和文件导入均由您主动操作。导出的文件或文字可能包含愿名和游玩信息；压缩、编码和校验不等于加密，请谨慎分享。

5. 您可以更改愿名、导出自己的数据，或通过本政策第七章说明的系统操作清除本机数据。手动保存在其他位置或分享给他人的副本，需要另外删除。

6. 访问本政策网页会产生必要的网络请求，Vercel 托管方可能处理 IP 地址等访问信息；这与离线游戏的数据处理不同。未成年人请与监护人一起阅读本政策。

本政策由 吴国黎（以下简称“我们”）制定，说明您使用《香火债》时哪些信息仅在本机处理、哪些信息可能因您的主动操作交给我们或第三方，以及您如何管理这些信息。隐私联系邮箱：carzyg@outlook.com。

本政策适用于上述已核对的客户端版本及展示本政策的网页。应用商店、GitHub、电子邮件、浏览器、操作系统及您自行选择的云盘或通信工具具有各自的数据处理规则；我们将在相关章节说明与本产品有关的接入或交互。

请阅读涉及权限、文件分享、删除数据、第三方托管及未成年人保护的内容。本政策是一项信息说明，不将继续游玩、浏览本页面或接受所有条款视为您对新增或非必要个人信息处理的一揽子同意。依法需要同意、单独同意或监护人同意时，我们将另行履行相应程序。

## 一、我们如何收集和使用您的个人信息

### （一）离线游玩与本机数据

离线功能没有手机号注册、实名认证、云存档、在线排行榜、内购支付或广告。可选对灯模式使用随机生成的匿名身份，不要求真实姓名或联系方式。客户端不收集或上传身份证号码、通讯录、精确位置、相机或麦克风内容、广告标识符或设备唯一标识符；单人愿簿、成就与成长不因联机自动上传。

为实现单机功能，客户端在您设备上处理并保存：您自愿填写的愿名；三个存档槽位的愿簿和进度；角色、武器、技能、成长、解锁及成就记录；本局地图种子、房间和战斗进度；音量、按键、显示、触觉反馈等设置。愿名最多 12 个字符，可以保留默认名称；不填写真实身份信息不影响游玩。

普通模式单局结束时，游戏还会自动在本机日志中记录时间、版本、地图种子、角色、武器技能、路线、房间和首领、胜负结果及战斗数值等观察记录，用于本机留存和您主动提供时的问题分析。该日志不会自动发送给我们，当前也没有独立的日志关闭开关；您可以按第七章删除日志，后续游玩仍可能生成新的记录。

游戏引擎还会在本机生成运行日志，可能包含引擎版本、图形或渲染设备信息，以及发生错误时的诊断内容。这些日志用于运行诊断，同样不会自动上传；只有您主动把相关文件发给我们时，我们才会收到其中内容。

运行时，客户端在本机读取键盘、鼠标、触摸或控制器输入，以及必要的屏幕、平台和设备运行状态，以适配操作、显示和触觉反馈。这些处理不用于跨应用跟踪或广告画像。普通游戏数据本身不一定能识别自然人；如果您填写了真实身份内容，或将文件与身份信息一并发送，相关内容可能构成个人信息。

### （二）权限、剪贴板与文件选择

Android 0.3.0 声明联网和振动普通权限，没有定位、通讯录、相机、麦克风、照片或广泛外部存储权限。联网仅在您进入对灯并主动连接所选服务器时用于该功能；拒绝连接不影响离线模式。剪贴板和文件选择不等同于申请 Android 危险权限。

| 权限或能力 | 使用目的 | 触发与授权 | 关闭或拒绝方式 |
| --- | --- | --- | --- |
| 振动 | 战斗与受击触觉反馈 | Android 普通权限；无运行时授权弹窗 | 在游戏设置关闭触觉反馈 |
| 剪贴板 | 复制种子或存档文字；粘贴存档 | 仅在您主动复制或粘贴时读写 | 不操作相关按钮；可清空系统剪贴板 |
| 本机文件 | 保存进度；手动导入导出存档 | 应用自有目录；外部文件由您在选择器中指定 | 取消导入导出；按第七章清除数据 |
| 网络 | 对灯匹配、房间、实时对战和重连 | Android 普通权限；首次连接每个服务器先说明并由您确认 | 不连接或退出对灯；可继续离线游玩 |

您点击“从剪贴板粘贴”后，客户端才读取当时的剪贴板内容，进行格式校验并展示导入预览；确认导入后才写入存档。它不会在后台持续读取或上传剪贴板。手动文件操作只处理您选择的路径，不为导入导出扫描整个设备。拒绝这些可选操作或关闭触觉反馈，不影响基本离线游玩。

### （三）您主动联系或分享信息

如果您通过本政策所列邮箱向我们咨询、申请权利或反馈问题，我们会收到您主动发送的邮箱地址、正文和附件。您附带的截图、日志或存档可能包含愿名、系统版本、文件路径或其他内容。我们仅在回复、定位您提出的问题或处理请求所必要的范围内使用这些信息，不要求您提供与该事项无关的身份证件、密码或完整设备资料。

请优先提供已遮盖无关个人信息的截图和最小问题样本。您在 GitHub 等公开平台发帖时，账号、正文和附件可能公开可见；隐私请求请使用第十章的联系邮箱，不要在公开问题区提交身份证件或其他敏感内容。

### （四）访问本政策网页

本网页是静态政策展示页，没有登录、表单、广告、用户画像或主动分析脚本，未接入 Vercel Web Analytics、Speed Insights 或第三方统计服务，也不会读取您的游戏存档。为传送页面、提供 HTTPS 及维持网络安全，浏览器和 Vercel 托管服务会处理必要的请求信息；托管方可能依其隐私声明处理 IP 地址、请求时间与网址、浏览器或系统信息、网络请求及安全日志等。

我们以提供您请求的功能、处理您主动提交的事项或履行适用法定义务等合法依据，在最小必要范围内处理信息。需要依赖同意的其他用途会事先说明并依法取得相应同意；本政策不授权我们为了营销、画像或未说明的用途额外收集信息。

### （五）您主动连接对灯服务器

客户端默认地址为本机测试地址，您可以填写自己或他人提供的服务器地址。同一比赛的两人需连接同一服务器。首次连接该地址前，客户端展示地址和信息处理范围，由您确认后连接；返回可取消。当前不提供预设的公共联机运营服务器。您选择其他运营者的服务时，请核对其主体、地区、隐私政策与联系方式。

服务器在连接期间接收连接 IP，以及协议和游戏内容版本、随机匿名身份、昵称（最多 16 字符）、还愿人／武器／技能配装、匹配或六位房间码、准备和选择请求、移动／瞄准／开火／技能操作、心跳和事件确认。服务器据此计算位置、伤害、构筑、回合与结果，并保存恢复对局所需的状态及胜负计数。它不接收您的离线愿簿或文件目录。

匿名恢复凭据在本机独立保存，服务器保存其摘要以恢复身份；六位房间码只用于找到房间，不是身份验证凭据。当前服务端代码不将 IP 或完整操作轨迹写入持久日志，不提供聊天、语音、通讯录、广告分析或在线排行榜。对手会收到您的昵称、配装、当前构筑、位置、攻击、血量及本场比分，不会收到恢复凭据或您的离线存档。运营者另行配置的网络代理日志以其说明为准。

## 二、我们如何保存您的个人信息

### （一）本机保存

离线存档、设置、游玩日志及联机客户端配置保存在您的设备上。Windows 默认位置为 %APPDATA%\IncenseDebt；Android 使用应用数据目录。联机身份、恢复凭据、所选地址、昵称、配装、待确认请求和最近显示的战绩使用独立 online-client 目录，并按服务器地址区分，最多保留八个地址。单人三槽存档与联机身份分开保存。

本机存档与单局观察日志没有设置统一的自动到期删除时间；通常保留到您主动清除、覆盖或由系统移除为止，引擎运行日志可能随运行轮换或覆盖。卸载 Windows 游戏可执行文件不会自动删除应用数据目录。当前 Android APK 已关闭系统应用自动备份；您手动导出的文件、自行上传云盘的副本及已分享给他人的副本仍由您或相应接收方管理。

联机状态保存在您选择的服务器，具体主机地区和运营者由该服务器提供者说明。随本版本提供的服务端默认保留断线对局 90 秒、等待房间 300 秒，使用双代校验检查点恢复状态；已结束房间从运行列表释放，未再连接且不在房间中的匿名身份和战绩在 14 天后清理。已释放且不被恢复检查点引用的房间文件在最后写入满 14 天后清理。运行中的对局和恢复所需的一代备份不会提前删除。运营者自建的备份、代理日志或调整的参数需另行说明与管理。

### （二）主动反馈及网页信息

对于您主动发送给我们的联系和问题资料，我们仅保存至完成回复、处理权利请求、必要的故障核查或履行法定保存义务所需的最短期间，目的完成后删除或匿名化；如依法必须继续保存，我们会限制其用途。您可以询问与您提交事项有关的具体保存情况，或要求依法删除。

本政策网页托管于 Vercel 的全球基础设施。必要的网页请求和安全信息可能在您所在地区以外处理；我们不承诺这些网页信息仅存储在中国境内。托管方的信息类别、保存原则、全球处理安排及权利渠道请参阅 https://vercel.com/legal/privacy-notice 。本网页未建立保存玩家档案的数据库，也没有自行配置长期用户行为记录。

离线功能不会自动向境外传输游戏文件。对灯的传输目的地是您确认的服务器地址，其主机及网络代理可能位于其他地区；请向运营者核对位置。若我们另行向境外提供我们持有的个人信息，将事先依法说明接收方、目的、方式、类别及权利渠道，并履行所需程序，不以本政策的一般说明替代。

## 三、我们如何使用 Cookies 和同类技术

离线游戏客户端不使用浏览器 Cookies、广告追踪像素或跨应用跟踪。客户端的本机存档及设置文件用于保存游戏功能状态，不作为广告标识符。

本政策网页未植入 Cookies、localStorage、指纹识别或统计分析代码，没有远程字体、广告嵌入或社交跟踪组件。托管方可能因防滥用、请求验证或其他必要安全机制，使用其管理的相关技术；具体以实际触发情况及 Vercel 隐私声明为准。

您可以通过浏览器管理网站数据、限制 Cookies 或清除缓存。浏览器或托管方的安全限制可能影响网页访问，但不会改变本机离线游戏的存档或功能。

## 四、我们如何共享、转让、公开披露您的个人信息

离线功能不自动发送玩家数据。对灯仅向您确认的服务器传输该模式所需信息，并向同场对手展示昵称、配装和对局状态。我们不会出售您的个人信息，也不会将您主动提供的资料用于广告投放或与广告商分享。网站托管所需请求信息由第五章列出的服务处理。

您主动导出、复制或使用其他应用分享存档时，由您决定接收方和传递渠道。导出包可能包含愿名、进度、成就和设置；请在分享前检查内容。客户端的导出操作本身不会替您上传文件，外部应用的发送、云端存储及公开行为受其规则和您的操作影响。

如果我们确需委托服务商处理您主动提交的信息，会限定目的、期限、方式、信息类别和保护要求并进行必要监督。若向独立的其他个人信息处理者提供信息，将依法告知接收方和相关处理情况，并在需要时取得您的单独同意。

除您的明确授权或适用法律要求外，我们不会公开披露您的联系内容、附件或其他个人信息。依法应有关机关要求提供信息时，我们会核验依据，并限定在依法要求的必要范围内；不会将一般的“安全”或“故障处理”理由视为任意披露的授权。

如果因合并、分立、解散等事项需要转移我们持有的个人信息，我们会依法告知接收方名称和联系方式，并要求接收方继续履行保护义务；改变原处理目的或方式的，依法重新取得相应同意。

当前游戏没有广告、支付、第三方账号、云分析或通用玩家统计 SDK。Godot 同时承载离线功能和您主动启用的 WebSocket 联机传输；对灯服务端独立于隐私网页的 Vercel 托管，网页不会代理或保存对战数据。

## 六、我们如何保护您的个人信息

产品使用本机应用目录、手动导入导出和校验减少离线数据损坏。对灯服务器验证内容版本、随机恢复凭据及输入序号，限制消息大小和速率，不接受客户端上传坐标、血量或胜负作为裁定。服务器保留可校验的恢复代，避免重复请求或恢复导致战绩重复。网页通过 HTTPS 提供，没有玩家资料表单。

公网对灯连接应使用具备有效证书的 wss 地址，客户端不关闭证书验证。ws 不加密，仅适合可信本机或局域网；无法防止同网络上的通信观察。请保护设备与本机恢复凭据，不公开分享 online-client 目录。服务器使用摘要保存凭据，但检查点中的昵称、状态和战绩不是加密文件；服务器运营者应控制文件权限和备份访问。

存档校验、Base64 编码与压缩不提供保密加密能力；本机文件和导出包不应被视为只有您才能读取的密文。请保护系统账户和设备访问权限，不向不可信的人发送完整存档或日志，并在共用设备上注意本机文件和剪贴板残留。

如发生涉及我们所处理个人信息的安全事件，我们将依法采取补救措施，评估影响，并依法律要求通知受影响人员及主管部门；直接通知难以实施时，以适当方式发布公告。我们不会以网络风险或第三方服务为由排除依法应承担的保护责任。

## 七、您如何管理您的个人信息

### （一）查阅、更正与复制

您可以在游戏的愿簿、角色与成就页面查阅本机记录，在愿名输入区域修改自己的愿名，并使用存档传递功能导出或复制自己的存档。导出包含的具体内容以当次预览及文件为准，不会同步到我们这里。对于您已经主动交给我们的资料，可以通过第十章邮箱申请查阅、复制、更正或补充。

### （二）删除本机数据

Windows：先退出游戏；如仍需保留进度，请自行备份。删除 %APPDATA%\IncenseDebt 文件夹可以清除该系统用户下的全部游戏槽位、设置、关联备份及本机日志。仅删除游戏可执行文件不会清除该目录。若只需删除单局观察日志，可以删除该目录中的 run_telemetry.jsonl；后续普通模式游玩结束可能重新生成该文件。

Android：在系统“设置—应用—香火债—存储”中选择“清除数据”（具体名称随设备而异），或卸载应用，可以清除应用自身的存档、设置和日志。该操作会丢失本机进度。另存至其他文件夹、云盘或第三方应用的手动导出副本，需要到相应位置另外删除。

我们无法远程读取、删除或恢复未提交给我们的离线文件。清除 online-client 可删除本机联机身份、配置和恢复凭据，但不会删除服务器已有的昵称或战绩，并会失去原身份的恢复能力。对灯大厅可查看最近服务器战绩；需查阅、更正或删除服务端资料时，请联系所选服务器的运营者，说明服务器地址和当前匿名身份，以最少必要信息核验。服务由我们运营时可使用第十章邮箱；不要公开发送恢复密钥。

### （三）选择、撤回与请求处理

您可以不填写识别身份的愿名或联机昵称、不使用剪贴板或导入导出、关闭触觉反馈、拒绝连接服务器、退出对灯并继续离线游玩。退出会停止该连接的数据传输；服务器已有资料按其保存和删除规则处理。当前没有手机号或密码注册账号；本机匿名身份的删除方式见上文，服务端删除需向对应运营者申请。撤回不影响撤回前依法开展的处理。

您有权依法要求解释本政策，并限制或拒绝相应个人信息处理。我们会在收到请求后十五个工作日内回复或说明处理进展。必要时，仅以与您原提交事项相匹配的最少信息核验请求，避免误删他人资料，不默认要求您上传身份证。合理请求原则上免费；如依法不能满足，将说明具体原因及可用的申诉途径。

## 八、我们如何处理未成年人的个人信息

未满十八周岁的用户请在监护人指导下阅读本政策，并由监护人协助管理设备、愿名、存档和对外分享。请勿在愿名、截图或反馈中填写学校、家庭住址、手机号等不必要的身份信息。

### 不满十四周岁用户的个人信息保护规则

不满十四周岁未成年人的个人信息需要严格保护。客户端不通过生日或身份证识别年龄；离线模式不自动向我们提交信息。请监护人协助管理昵称、文件分享，并在同意连接对灯服务器前阅读其信息处理说明。服务器不设年龄识别或监护关系收集接口，不应通过昵称提交儿童真实姓名、学校或联系方式。

若因咨询、请求或其他确有必要的事项，需要我们处理不满十四周岁用户的个人信息，我们将先向监护人说明具体目的、必要性、信息类别、使用及保存方式，并依法取得监护人同意及需要的单独同意。仅处理完成该事项所必要的信息，不将其用于广告画像或公开展示，也不因处理该事项收集无关资料。

监护人可以通过第十章邮箱申请查阅、更正、复制或删除其监护对象已交给我们的信息。若发现未经合法监护人同意而持有儿童个人信息，我们将尽快停止相关处理并依法删除；法律要求保留的除外。核验监护关系时遵循最小必要原则。
