# 香火债 / Incense Debt v0.6.0

0.6.0 将双人合作战斗从容易产生队头阻塞的 WebSocket 数据通道切换为 Godot 原生 ENet＋DTLS。WSS 只负责匿名身份、房间和一次性 battle ticket；战斗状态、输入和控制消息在专用 UDP 18779 上分通道传输。现网 `/play` 已使用同一版本的 Linux x64 服务端。

Incense Debt 0.6.0 moves two-player battle from a head-of-line-prone WebSocket data path to native Godot ENet over DTLS. WSS now bootstraps anonymous identity, room membership and a one-use battle ticket; battle state, input and control traffic use separate channels on UDP 18779. The production `/play` route runs the matching Linux x64 server.

## 联机可靠性 / Multiplayer reliability

- 60 Hz authoritative simulation with bounded 20 Hz snapshots.
- ENet channel 0 carries reliable ordered state; channel 1 carries redundant unreliable input; channel 2 carries reliable control and rebind messages.
- Client-side fixed-tick input buffering, short prediction and remote interpolation hide ordinary jitter without inventing server state.
- Bootstrap and battle lifecycles are independent. A dead WebSocket cannot leave a playable UDP peer hanging, and an unavailable UDP port cannot silently fall back to TCP.
- A battle bind deadline and silence deadline bound recovery. Reconnect reuses the same identity and room only inside the grace window, then requires both players to confirm.
- DTLS certificate rotation is staged and applied only when the service is idle. Retired UDP tuples are quarantined before reuse.

## 验收 / Acceptance

本版本使用原生 Godot headless client、Windows packaged client、Linux server and an actual public WAN candidate. 最终公网四 Session／两房运行 62.665 秒：tick 59.146 Hz、状态年龄 P95 42 ms、ping P95 133 ms、p99 模拟步长 7.125 ms、p999 23.5 ms、>100 ms 战斗阻塞 0。最终运行没有触发重绑；重绑、UDP 不可达、丢包、重复、乱序、突发和故障恢复由独立应用回归覆盖。

The final public four-session/two-room run lasted 62.665 seconds at 59.146 Hz, with state age P95 42 ms, ping P95 133 ms, p99 simulation step 7.125 ms, p999 23.5 ms and zero combat stalls above 100 ms. No rebind occurred in that run; rebind, UDP-unavailable, loss, duplication, reordering, burst and application recovery are covered by separate regressions.

## 升级 / Upgrade

Android 优先覆盖安装，勿先卸载，否则会删除本地愿簿。Windows 直接解压新 ZIP。服务端升级前先正常停机并备份 `/var/lib/incense-debt`，再使用 `server/README.md` 中的 systemd 流程；`server/archives/v0.6.0/` 是与本 release 绑定的公开源归档。

Install the Android APK over the previous package when possible; uninstalling deletes local saves. Extract the Windows ZIP. Stop the server gracefully and back up `/var/lib/incense-debt` before upgrading. The public server archive is pinned at `server/archives/v0.6.0/`.
