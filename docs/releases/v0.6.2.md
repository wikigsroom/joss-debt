# 香火债 / Incense Debt v0.6.2

0.6.2 是水墨朱砂符 UI 与移动端菜单适配修订版。所有主要菜单、暂停、道具/愿簿选单、供物选择、存档导入、故事阅读和战斗 HUD 统一使用真实字体度量、文字安全框和九切笔刷按钮；移动端普通按钮不再被统一拉伸，长文本支持手指滚动，列表复位时不会残留惯性导致短按失效。

Incense Debt 0.6.2 is the Ink Cinnabar UI and mobile-menu compatibility release. Main menus, pause, inventory/build pages, relic choice, save import, story reading and the combat HUD now share measured text bounds and nine-slice brush buttons. Ordinary mobile buttons keep their visual proportions, long text scrolls by touch, and a list reset cancels stale inertia so the next tap remains reliable.
