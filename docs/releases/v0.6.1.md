# 香火债 / Incense Debt v0.6.1

0.6.1 是原生 ENet/DTLS 联机链路的延迟体验修复版。客户端加入单调状态时钟、自适应插值、短时有界外推和本地移动预测纠正，降低公网抖动时的抽搐、移动闪回和步骤闪回；服务端继续以 60 Hz 权威裁定移动、碰撞、命中、掉落和成长。

Incense Debt 0.6.1 is a latency-experience patch for the native ENet/DTLS battle path. The client now uses a monotonic state clock, adaptive interpolation, bounded short extrapolation and smooth local prediction reconciliation to reduce jitter and movement rollback on ordinary WAN variance. The server remains authoritative for movement, collisions, hits, drops and progression at 60 Hz.

## 主要更新 / Highlights

- 本地玩家使用预测、输入重演和 1.5 px 死区的平滑纠正；只有超过 420 px 的场景级断层才硬切。
- 远端玩家、敌人和子弹使用 50–220 ms 的 RTT/抖动自适应缓冲，最多外推 100 ms，并拒绝过期快照。
- 房间切换会清理旧预测与插值历史；暂停请求在 `stale_context` 时只重试一次，避免菜单状态来回跳变。
- 官方服务端同步到本版本，战斗仍通过加密 ENet/DTLS UDP 18779，WSS 只负责身份和一次性入战票据。

The release also refreshes the signed Android arm64 package, Windows x64 client and Linux/Windows native server packages. Android package inspection and signing checks pass; physical Android validation was not performed in this release.

## 验收 / Acceptance

本版本复用了已通过的全量素材、键盘和公网合作流程，并针对延迟修复重新导出包体。Windows 公网合作流程 29/29 通过；客户端插值、状态流、合作传输、网络故障和战斗回归均通过。公网烟测约 30 秒，tick 约 60 Hz、ping P95 约 51 ms、状态年龄 P95 约 33 ms、可玩帧比例 1.0，超过 100 ms 的战斗阻塞为 0。没有使用 Docker、WSL、虚拟机或模拟器。

The packaged Windows cooperative flow passed 29/29 checks. Interpolation, state stream, cooperative transport, network-fault and combat regressions passed. A roughly 30-second public WAN smoke run stayed near 60 Hz with about 51 ms ping P95, 33 ms state-age P95, a 1.0 fresh-playable-frame ratio and zero combat stalls above 100 ms. No Docker, WSL, VM or emulator was used.
