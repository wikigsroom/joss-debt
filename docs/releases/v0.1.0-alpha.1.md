# 香火债 / Incense Debt · v0.1.0-alpha.1

**十一层可玩 Alpha 的首次 GitHub 预发布。**

这是一款离线单人 2D 房间动作肉鸽，以“挂余烬 → 连债 → 焚债 → 收灰”构成战斗循环，使用纸偶、墨、火、红绳与铜器建立视觉主题。游戏界面与叙事目前为简体中文；项目 README、安装说明与本发布说明为中英双语。

## 当前游戏内容

- **11 层正式流程**：第 6 层剧情首领，第 7—10 层主线双首领，第 11 层 40 房、连续六个独立首领房与最终总账。
- **20 套独立地图主题、40 张背景**；每套 12 种专属小怪与 3 名 Boss，最终天穹为 7 名 Boss。
- **6 名角色、6 条成长路线、32 件武器、18 种角色技能形态**。
- **54 件遗物、36 个行愿节点、24 套登记联动、9 类债约、22 项局外解锁**。
- **32 项成就**：每名角色四项，另有八项共享成就；角色详情、个人愿簿与记录页显示进度。
- 商店及免费独立试射、献灯、判官、观音、破阵、事件、债约、秘密与首领房。
- 大圆角、图标化 UI、随包字体、紧凑 HUD、暂停页完整成长历史。
- **三个独立存档槽、schema 2 校验与两代恢复、旧档迁移、文件 / 压缩文字传递、导入前备份**。
- 9 套音乐主题、25 条自适应分层，独立 BGM / SFX 音量与事件音效。

## 当前关键规则

清房后需要**走进实际方向门口**才能进入相邻房间；地图用于查看路径。第 **1—5 层每层两个独立单 Boss 房**，分别位于主线出口和随机支路。正式遭遇按 **60% 本土 + 40% 同层随机高对比外来主题**混编；固定剧情首领保留身份。

40 张背景按内侧围墙校准碰撞，实体半径、身法、击退、敌人寻路、弹道和射线使用一致几何。射线与范围攻击加入预备、主体、扩张及余辉阶段，包含 8 条特效、48 张生成关键帧。

## 快速操作

WASD 移动；鼠标 + 左键或方向键瞄准射击；Q / 右键焚债；Space 身法；E 交互；1—4 选择成长候选；Tab 行路图；I 构筑；Esc 暂停 / 返回；Enter 确认；F11 全屏。菜单、技能多选、供物替换、商店、特殊房、偿债与结局有纯键盘路径。手机采用独立双摇杆与施术 / 身法按钮。

Windows 存档在 `%APPDATA%\IncenseDebt\`。升级前关闭游戏并备份目录；恢复游戏先暂停并要求确认。跨设备传递位于设置 → 愿簿传递，导入有预览和可恢复备份。

## English

**The first GitHub prerelease of the playable eleven-floor Alpha.**

Incense Debt is an offline, single-player 2D room-action roguelite built around **Mark → Chain → Burn Debt → Recover Ash**, with paper spirits, ink, incense, red thread, and brass. The game UI/story currently uses Simplified Chinese; the repository, installation guide, and release notes are bilingual.

### Content and behavior

- **11 floors**: floor 6 story boss, paired main-route bosses on floors 7–10, and a 40-room final floor with six separate consecutive boss rooms and the final ledger.
- **20 environment themes / 40 backgrounds**, each with 12 native mobs and 3 bosses; the final sky theme has 7 bosses.
- **6 characters, 6 routes, 32 weapons, 18 skill forms**, 54 relics, 36 talents, 24 registered synergies, 9 contracts, and 22 meta unlocks.
- **32 achievements**: four per character plus eight shared goals, exposed through character details and records.
- Shops with isolated free weapon trials, sacrifice/Judge/Guanyin/challenge rooms, events, contracts, secrets, and boss chambers.
- Rounded/icon-led UI, bundled fonts, compact HUD, full build-selection history in pause, and keyboard menu navigation.
- **Three independent save slots**, validated schema 2, two-generation recovery, legacy migration, file/text transfer, and pre-import backup.
- Nine musical themes, 25 adaptive stems, separate BGM/SFX controls, and event-specific effects.

Room transitions require **physically entering an open doorway** after clearing. Floors **1–5 have two separate single-boss rooms per floor**, one at the main exit and one on a randomized side branch. Encounters mix **60% local + 40% one randomized contrasting guest theme per floor**, while story bosses retain their identities.

All forty backgrounds use calibrated inner walls shared by body clearance, dashes, knockback, enemy navigation, projectiles, and beams. Staged beam/area visuals add anticipation, active bodies, expansion, and afterglow, using eight effect strips from 48 generated keyframes.

### Controls and saves

WASD moves; mouse + left button or held arrows aim/fire; Q/right mouse casts Burn Debt; Space dodges; E interacts; 1–4 selects growth options; Tab shows the map; I shows the build; Esc pauses/returns; Enter confirms; F11 toggles fullscreen. Menus, sequential skills, replacements, shops, special rooms, repayment, and endings have keyboard paths. Mobile uses separate dual sticks and skill/dodge buttons.

Windows saves live in `%APPDATA%\IncenseDebt\`. Close the game and back up that directory before upgrades. Resumed runs start paused. Settings → Save transfer provides file/text import with preview and recoverable backup.

### Validation and limits

The fresh Windows export passed **75 native GUI interactions, 105 keyboard checks, 90 native GUI captures, and loading all 3,665 runtime resources**. `release-manifest.json` binds the verification summary to its EXE hash.

Existing evidence for the same game source includes 373 combat-revision checks, 509 expansion-system checks, 285 packaged-expansion checks, 22 native audio checks, and one unchanged-initial-stat Umbrella Spirit eleven-floor action-bot victory with 129 cleared rooms, 153 physical doorway transitions, and ten floor-transition save/restores. Check categories overlap; their sum is not coverage. Bot success does not establish human feel or balance.

Android has package/signature/permission/resource evidence, with physical-phone input, thermals, keyboards, and clipboard acceptance pending. iOS has no Xcode project, signed IPA, or verified device run. This remains an Alpha pending long human sessions and build balance. Environment themes share some music families, and English game localization is pending.

### 原生复现 / Native reproduction

在已安装匹配 Godot / 模板且有当前已验证平台产物的 Windows 工作区运行：

In a native Windows workspace with matching Godot/templates and the currently verified canonical platform artifacts:

```powershell
python tools/runtime/package_release.py
```

导出、原生窗口检查、包体与校验文件写入被忽略的 `build/release/v0.1.0-alpha.1/`。仅打包说明变化可用 `--reuse-export`，该选项核对已导出 EXE 与此前原生检查的哈希。发布工具 `python tools/runtime/publish_release.py` 要求提交说明与清单、推送 `main` 和带注释标签，并使用本机已经授权的 `gh`。工具先上传到草稿、核对 GitHub 端每个附件的 SHA-256，再公开预发布；重复执行跳过一致附件。

Exports, native QA, packages, and checksums go to ignored `build/release/v0.1.0-alpha.1/`. For packaging-only changes, `--reuse-export` validates the existing EXE against its passing native checks. `python tools/runtime/publish_release.py` requires committed notes/manifest, pushed `main` and annotated tag, and an authenticated local `gh`. It uploads to a draft, checks each server-side SHA-256, then publishes the prerelease. Repeated calls skip matching assets.
