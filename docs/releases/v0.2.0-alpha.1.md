# 香火债 / Incense Debt · v0.2.0-alpha.1

主动道具、单槽饰品、稀有掉落与攻击组合更新。保留十一层、二十地图主题、六角色和三个存档槽的离线单人玩法。游戏界面为简体中文；README、安装及发布说明为中英双语。

## 本次更新

- **12 件主动道具**：F 使用，手柄 X、独立触控按钮；单槽交换，普通清房充能 +1、首领 +2、火芯 +1。包含爆弹、回血、反射、墨池、五道红线、追踪纸鹤、收灰、跟随莲印、重掷、冻结、加速和跳跃雷签。无效使用不扣充能，换装保留实际剩余充能。
- **12 件单属性饰品**：最多持有一件。E 拾取新饰品时旧饰品落地，反复交换不会累积属性。
- **稀有掉落**：普通敌人基础概率 0.8%、精英 2.5%、首领 8%、首次清房 3.5%，每房最多两件；召唤和训练排除，回访与读档不能刷取。宝藏房另有一次性装备底座。
- **12 件攻击修饰供物**，总计 66 件。三 / 四 / 五发取最高档；支持五发＋射线＋爆炸，以及穿透、追踪、操控、反弹、分裂、持续场和蓄力，统一接入 32 武器。范围伤害去重，子代与回响触发受限。
- **Tab 顶部完整十一层路线**；I 装备详情、暂停完整成长历史和新装备图鉴。旧自定义按键冲突可迁移。
- **80 条新特效 / 480 个独立生成帧**，十个家族；与原八条合计 88 条分阶段战斗动画。395 份敌人弹丸参数结合 16 种形态、不同尺寸、颜色、旋转和尾迹，保留危险外沿、内墙裁剪和有上限的轮廓缓存。
- 充能、地面交换、稀有来源账本、控制弹、延迟攻击构成和替换事务进入存档；继续兼容 schema 2。

## English

Active equipment, one trinket slot, rare loot, and attack composition join the offline eleven-floor Alpha. The game UI remains Simplified Chinese; guides and README are bilingual.

- **12 active items**, one slot, `F` / gamepad `X` / dedicated touch control. First room clears charge +1, bosses +2, batteries +1. Swapping preserves charge, and invalid use spends nothing.
- **12 single-stat trinkets**, exactly one held. `E` exchanges equipment and drops the previous item; bonuses never accumulate through swaps.
- **Rare loot**: 0.8% ordinary kills, 2.5% elites, 8% bosses, 3.5% first clears, capped at two per room. Summons, training, revisits, and save-load farming are excluded. Treasure rooms offer once-only equipment pedestals.
- **12 attack-modifying offerings**, 66 total relics. Three/four/five-shot tiers take the highest minimum. Five-shot + beam + explosion yields five explosive beams; pierce, homing, control, bounce, split, linger, and charge integrate across all 32 weapons, with overlap deduplication and bounded secondary generations.
- **Eleven-floor map timeline**, equipment inventory, full pause history, new discovery tabs, and older custom-binding migration.
- **80 new effects / 480 distinct generated frames**, ten families, 88 staged combat strips overall. All 395 enemy/boss sources have projectile parameters based on 16 shapes, size, spin, color, and trails, with danger outlines and wall clipping.
- Charges, ground swaps, loot ledgers, controlled shots, delayed recipes, and replacement transactions persist in compatible schema-2 saves.

Extract the Windows ZIP and launch `IncenseDebt/IncenseDebt.exe`, without installing Godot. The arm64 Android APK is debug-signed for Android 7/API 24+. The iOS ZIP is shared source for real-Mac/Xcode export, **not a signed IPA**. Installation guides, the manifest, and checksums accompany all packages. Back up `%APPDATA%\IncenseDebt\` with the game closed before upgrading.

Validation: 1,568 equipment/composition checks, 80,000 rare-roll samples, 509 expansion and 373 collision/encounter checks; an unchanged-stat eleven-floor action-bot victory with 129 clears, 151 physical doors, 40 active uses, 13 swaps, and ten restores; 75 native GUI, 107 keyboard, 285 expansion, and 29 equipment checks with 111 equipment captures and all 480 new frames. Audio and source-art checks also pass. All 69 packed Windows/Android scripts match, Android includes 3,781 runtime resources, and the iOS source tree matches the project.

The final export receives the same native verification; completed evidence is reused only for a byte-identical executable. The 205-projectile renderer benchmark has a 34.24 ms P95 against a 50 ms limit, with physics paused. It does not establish mobile or full-run performance. Physical Android acceptance, signed iOS export, and human long-term balance remain pending. All tooling runs natively on Windows without Docker, WSL, browsers, or virtualization.
