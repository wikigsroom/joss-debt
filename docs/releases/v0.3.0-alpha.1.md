# 香火债 / Incense Debt · v0.3.0-alpha.1

新增独立双人实时对战「对灯」及 Windows 原生专用服务端。主菜单进入联机大厅，选择角色／武器／技能，通过快速配对或相同六位数字开房；每轮四选一、倒数开战、先赢两轮获胜。双方可暂停、查看历史构筑、断线恢复、结算与再战。

This release adds a separate two-player real-time Duel mode and standalone native Windows server. Enter Duel from the main menu, choose a loadout, use quick matching or the same six-digit room code, draft each round and fight to two round wins. Both players can pause, inspect build histories, reconnect and rematch.

## 新内容 / Changes

- 服务端裁定战斗、输入、伤害、回合与唯一结果，客户端做快照表现和移动预测。六角色、32 武器、18 技能、32 件 PvP 供物开放；复用生成纸偶、美术、地图内墙、粒子、BGM 和音效。 / Authoritative combat and results, snapshot presentation and movement prediction; existing generated art/effects/audio with all PvP loadouts available.
- 快速 FIFO 配对；双方输入同一六位数字进入开放双人房，保留前导零。 / FIFO matching and six-digit two-player rooms, preserving leading zeroes.
- 90 秒断线保留、自动退避重连、双方确认恢复；旧连接接管、旧按键清空、请求去重和结果单次结算。 / 90-second grace, automatic reconnect, mutual resume, takeover, input clearing and deduplicated controls/settlement.
- 双代一致检查点与后台写盘；重启恢复原房间，损坏回退；写盘失败主动停战。 / Consistent generations, background persistence, restart recovery, corruption fallback and proactive suspension on storage faults.
- 键盘完整联机流程，1–4 选卡、Esc 暂停、I 双方历史、Tab 战术图；保留左手移动／右手战斗及长屏适配。 / Complete online keyboard flow and existing mobile control/safe-area handling.
- 隐私政策 1.4 同步公开，主体吴国黎、邮箱 carzyg@outlook.com。Android 增加 INTERNET，离线愿簿不上传。 / Updated public privacy notice and Android INTERNET permission; no solo-save upload.

同电脑两端填写 `ws://127.0.0.1:18777`；局域网填写服务主机 IPv4，如 `ws://192.168.1.10:18777`，主机允许 TCP 18777。双方连接同一服务器、相同版本，快速配对或输入同一六位数字，再各自准备。

Use localhost for two same-PC clients or the host's LAN IPv4 for other devices. Permit TCP 18777. Both players connect to the same server/version, match or use the same six digits, then ready.

## 验证与适用边界 / Verification and limits

双人战斗 271 项、真实传输 26 项、原生独立服务端恢复 57 项、写盘故障 7 项通过。源码及实际客户端各通过 30 项联机菜单／输入、33 张捕获；实际 EXE 编译包另经原生外部录制脚本通过 33 项触控／联机检查，验证右摇杆持续开火与右手技能。实际 Windows 包另复测 107 项离线键盘流程，Windows／Android 编译资源和联机模块已核对。全部证据及真实战斗 GIF 见[交付验收](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/docs/incense-debt/40-online-delivery.md)与[README](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/README.md)。检查类别存在交集，不相加为覆盖率。

Passing evidence includes 271 combat, 26 transport, 57 server recovery and seven storage-fault checks; 30 online checks/33 captures for both source and exported client; 33 additional compiled-pack checks using an external native touchscreen recording driver; 107 offline keyboard checks in the actual EXE; and client package/resource verification. See the [acceptance report](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/docs/incense-debt/40-online-delivery.md) and [README](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/README.md) for evidence, limits and native GIFs. Categories overlap.

最终服务端两房／四客户端、射线与分裂弹 60 秒测试约 **59.43 Hz**，回环 P95 ping **18 ms**，无持久化错误；另保留早一版服务端 180 秒两房测试。默认上限两房、16 连接，更高负载探索未全部达标。公网延迟、长期运行及目标机器容量须另行验收，不能以本机短测代替。

The final two-room/four-client 60-second beam/split-shot benchmark sustained about **59.43 Hz**, with **18 ms** loopback P95 ping and no persistence errors. A prior-build 180-second run is retained separately. Defaults are two rooms/16 connections; larger exploratory loads did not all pass. WAN latency, extended operation and deployment-host capacity need separate acceptance.

当前提供可直接运行的本机／局域网联机。**没有部署默认公网游戏服务器**；公网 WSS 常驻主机配置见 [server/README.md](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/server/README.md)。[xhz.sidcloud.cn](https://xhz.sidcloud.cn/privacy-policy) 是已公开的隐私网页。Windows 未做发行签名，Android 为调试签名，未连接实体 Android 验收；旧 iOS 交接仍为 0.2.0，无签名 IPA。

Local/LAN multiplayer is immediately runnable. **No default public game host is deployed**; see [server operations](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/server/README.md) for WSS hosting. The privacy page is public. Windows lacks publisher signing; Android is debug-signed and has no physical-device acceptance; iOS keeps the historical 0.2.0 source handoff without a signed IPA.

实际服务端 ZIP 解压至含空格路径后的启动、健康检查、优雅停机与检查点保存 4 项通过。 / The actual server ZIP also passes four native checks for launching in a path with spaces, health, graceful shutdown and durable adjacent data. See the [package smoke receipt](https://github.com/wikigsroom/joss-debt/blob/v0.3.0-alpha.1/docs/releases/v0.3.0-alpha.1.package-smoke.json).
