# 香火债 / Incense Debt · v0.2.3-alpha.1

本次更新发布 Windows x64 和 Android arm64 试玩包，将 0.2.1～0.2.3 的角色／怪物动作、生成掉落物、长屏适配与右手战斗键位同步到公开版本。十一层离线单人 Alpha；游戏界面为简体中文。

This release brings the 0.2.1–0.2.3 character/creature animations, generated pickups, widescreen support and right-hand combat controls to the public Windows x64 and Android arm64 builds. It remains an offline, single-player, eleven-floor Alpha with a Simplified Chinese game interface.

## 本次变化

- **左手只负责移动。** 手机、平板默认布局均把身法位移、焚债／爆炸技能与主动道具放到右侧，围绕瞄准／射击摇杆排列。无主动道具时隐藏对应按钮。
- **已有键位按设置迁移。** 完整的旧手机／平板默认位置自动升级；已自定义位置、单独大小与透明度保留。如果旧尺寸过大导致新位置重叠，保留原合法布局。设置 → 触控 → 恢复默认 → 保存可主动切换。
- **长屏完整铺景。** 保留 0.2.2 的长屏背景延展、Android 全屏与边到边显示，适配左右前摄、独立打孔、安全区、密度与横屏翻转；房间、内墙碰撞、出口与人物保持原比例。墙外延展属于环境背景。
- **掉落物使用生成素材。** 红心改为暖红纸灯笼，搭配铜钱、双铜钱、灰袋、高阶灰袋与充能火核。六类物件、19 张透明位图统一用于掉落、HUD、商店与拾取反馈，并有浮动、发光和减少动态选项。
- **人物与怪物动作完整打包。** 六位角色共 864 帧四向独立动作；402 个怪物身份共 1,002 张攻击／受击图集、24,048 帧；32 种武器的持械表现与 24 帧绘制特效进入两个平台的实际运行包。
- **移动操作与配乐同步。** 五个触点可分别调整位置／大小，支持固定／浮动摇杆、试操作与安全区；四首 Yourset 曲目默认随机轮播、交叉淡化，切房不中断。保留 PC 方向键射击、1～4 选项、Tab 地图、Esc 暂停和完整键盘菜单。
- **愿簿与隐私保持一致。** 三槽愿簿、存档格式 2、导入预览和导入前备份保持。隐私主体为吴国黎，邮箱为 `carzyg@outlook.com`。

## Changes

- **Movement stays on the left.** Both phone and tablet presets place dash, Burn Debt/explosion and the equipped active item on the right, around the aim/fire stick. The item button appears when an active item is equipped.
- **Existing settings migrate conservatively.** Exact old phone/tablet defaults upgrade automatically. Custom positions, individual sizes and opacity remain intact. Oversized old controls retain their valid layout if migration would cause overlap. Settings → Touch → Reset defaults → Save installs the new preset.
- **Widescreen scenery fills the surface.** Includes the 0.2.2 scenery extension, Android immersive/edge-to-edge flags, cutout/punch-hole protection, safe areas, density handling and landscape flips. Rooms, inner-wall collisions, exits and actors retain their proportional projection; scenery outside the walls is decorative.
- **Generated collectible objects.** A warm red paper lantern replaces the heart graphic, alongside brass coins, double coins, two ash pouches and a charge ember. Six objects and 19 transparent bitmaps serve world drops, HUD, shops and collection feedback, with bobbing, glow and reduced-motion support.
- **Complete character and creature animations.** Includes 864 directional hero poses, 1,002 attack/hurt atlases and 24,048 poses across 402 creature identities, plus held-weapon rigs for all 32 weapons and 24 drawn effect frames in both packages.
- **Mobile interaction and music updates.** Five independently adjustable controls, fixed/floating sticks and a practice screen accompany a four-track Yourset shuffle playlist with crossfades. Room changes do not restart songs. PC keeps arrow-key firing, 1–4 choices, Tab map, Esc pause and keyboard menu navigation.
- **Save and privacy continuity.** Three slots, save schema 2, import previews and pre-import backups remain. The privacy operator is 吴国黎; contact: `carzyg@outlook.com`.

## 存档升级 / Save upgrades

Windows 先退出游戏，备份 `%APPDATA%\IncenseDebt\`，再解压新版到独立目录运行；同一应用存档目录继续读取原愿簿。Android 使用相同包名 `org.incensedebt.game`，当前签名已与前一份本地 0.2.2 APK 比对一致，可直接覆盖该包保留数据。手机升级前可在设置 → 愿簿传递导出文件或文字；卸载会删除应用私有存档。自定义触控设置继续保留。

On Windows, quit and back up `%APPDATA%\IncenseDebt\`, then extract the new ZIP into a separate folder. Existing save slots use the same application-data directory. Android retains package ID `org.incensedebt.game`; its signing certificate matches the previous local 0.2.2 APK, allowing an in-place upgrade from that package. Export a save file or transfer text through Settings → Save transfer before updating. Uninstalling removes private app saves. Custom touch settings remain.
