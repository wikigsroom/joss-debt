# 香火债 / Incense Debt v0.4.0-alpha.1 — 共灯合作 / Co-Light

双人一起闯十一层肉鸽。此版本把联机默认玩法改为合作：双方对抗同一批怪物与 Boss，共享场景、掉落和纸钱，各自选择成长、武器、技能与债约。一人倒地可由队友靠近按 E 救援；两人走到同一扇真实门或阶梯才能推进。离线单人和可选「对灯切磋」继续提供。

Two players share the actual eleven-floor roguelite campaign, NPCs, bosses, loot and coins, while keeping personal health and builds. Rescue a fallen teammate nearby with E; approach the same physical door or stairs together to advance. Solo and optional Duel remain available.

双方使用 0.4.0 客户端，连接同一服务器并选同一模式。运行服务端 `StartServer.cmd`，在「共灯 → 服务器」填写地址；同电脑用 `ws://127.0.0.1:18777`，手机／另一电脑用服务器的局域网 IPv4。快速匹配或输入相同六位码，双方准备后出发。默认没有公网游戏主机。

Use matching 0.4.0 clients and server, with the same mode. Run StartServer.cmd and set the address in Co-Light → Server. Localhost works on the server PC; LAN phones use that PC's IPv4. Quick-match or enter the same six-digit code, then both ready. No default public game host is included.

## 操作和修复 / Controls and fixes

- WASD 移动、方向键射击、Space 身法、Q 技能、E 拾取／救援、F 主动道具；1–4 选卡，Tab 地图，I 双方成长记录，Esc 暂停。Mobile keeps movement on the left and aim, dash and skills on the right.
- 合作菜单暂停双方在线时不会超时；断线后默认 90 秒恢复，双方确认后继续。Connected co-op menu pauses have no disconnect deadline; a real disconnect starts the 90-second recovery window.
- 保存完整共享房间与个人成长；两代检查点分别使用独立房间文件。重复 E 不重置救援，短暂网络陈旧不丢失摇杆手势，结果界面可正确退出地图／成长页。Full shared and personal state is durable; registry generations have independent room files. Repeated E preserves rescue, brief stale snapshots retain held sticks, and terminal results override open map/build pages.
- 单人三槽存档、角色解锁和成就独立保留；合作结果与 PvP 战绩分开记录。Offline slots, character unlocks and achievements remain separate from online identities and results.

## 验收与限制 / Acceptance and limits

本轮最终包：合作规则 125 项、真实传输 32 项、实际服务端恢复 57 项、写盘故障 7 项；实际 Windows 合作流程 27 项／31 张捕获、PvP 流程 30 项、离线键盘 107 项；跨包核对 2171 项、90 份编译脚本一致，客户端／服务端 37 份共享编译模块一致，全部通过。两房四客户端 60 秒本机实测 59.18 Hz。

Final-package acceptance passes 125 co-op rule, 32 transport, 57 packaged-server recovery, 7 storage, 27 packaged-client co-op and 30 Duel flow checks, plus 107 offline keyboard and 2171 package checks. 90 client scripts match Windows/Android; all 37 shared compiled client/server modules match. Four clients in two rooms sustained 59.18 Hz during the 60-second local test.

GIF 与截图来自此版实际 Windows EXE、独立原生服务端及两个真实网络客户端，触控用 Windows 原生输入夹具；不能称为 Android 真机。负载是本机首房间的 60 秒短测，不是公网或十一层长时容量。Android 是调试签名，与旧本机 APK 签名相符；发行签名、实体设备、真实 WAN 与多人真人长期平衡仍待验收。iOS 保留 0.2.0 历史交接，没有新版 IPA。

Media uses this actual Windows EXE, a separate native server and two real network clients. Touchscreen fixtures are native Windows tests, not physical Android. Load results cover a short local first-room run, not WAN or a full campaign. Android is debug signed with upgrade-signer continuity; physical devices, production signing, WAN and human long-campaign balance remain unverified. No updated iOS IPA is included.
