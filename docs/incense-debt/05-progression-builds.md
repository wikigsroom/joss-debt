# 多成长路线与局内、局外进度

## 三种成长相互分工

**行愿节点**让每局逐步选择稳定方向；**遗物**提供会改变行为的随机关键件；**角色焚债演化**在二层起点固定给出个人技能二选一。六条路线可以跨角色混搭，路线标签用于提示和温和推荐，不封锁装备。

## 六条行愿路线

| 路线 / ID | 核心动作 | 三个阶段关注点 | 必须保留的取舍 |
| --- | --- | --- | --- |
| 烬火 / fire | 灼烧、区域、焚债扩散 | 点燃稳定 → 传播 → 烧尽爆发 | 持续伤害有延迟，需要安排引爆 |
| 红绳 / thread | 连债、控制、目标关系 | 多目标挂线 → 收紧 → 跨阵连锁 | 敌人太分散时要主动组织位置 |
| 归灰 / ash | 拾灰、能量、灰弹回击 | 回收可靠 → 返击 → 循环 | 无击杀的 Boss 阶段要依赖基础恢复 |
| 镇印 / seal | 正面招架、纸甲、反击 | 生存窗口 → 定点反击 → 破阵 | 覆盖范围和移动节奏需要补强 |
| 游风 / wind | 身法、回旋、位置收益 | 位移可靠 → 路径攻击 → 双向打击 | 需要持续走位并控制返程路线 |
| 墨契 / ink | 穿透、延迟、风险与精度 | 对线挂印 → 延迟结算 → 同线勾销 | 对齐目标的收益高，围攻时压力大 |

每路线有六个行愿节点，分三阶、每阶两个，共三十六个。第一阶为方向性基础；第二阶要求该路线已投入至少一点；第三阶要求该路线已投入至少两点。完整节点行为在数据库。

## 行愿与经验

愿力是自动入账的单局经验，不生成地面拾取物。普通清房 10、精英 18、Boss 30；同一房间只计一次。累计阈值为 20、50、90、140、200、270，最多六次选择。

每次升级暂停并提供三个不同节点。节点池优先使用当前等级对应阶，合格路线不足时允许补充未选过的低阶节点；保证至少三个候选。当前已投入路线仅提供温和的权重提升，玩家始终可选择新路线。不能再获得已持有的唯一节点。

完整探索三层基础房间得到 324 愿力，足够六次选择；主路少战房的玩家可能以五次选择结束，以更短路线换少量成长。选择预览显示射击或技能小演示、主要影响和兼容标签。

## 构筑骨架

每角色携带一种主武器、一个焚债形态、行愿节点和遗物。遗物上限十二槽，重复可堆叠遗物继续占同槽并按定义升级；达到上限的新遗物进入安全的替换面板，可选择留在地面或换出旧件。换出后重新计算属性与连接规则。

被动体系按规则层组合：武器提供发射器；角色提供天赋；节点修改基础行为；遗物监听有限事件；技能使用最终规则快照。描述中明确“主攻击”“自然击杀”“焚债首段”等限定条件。

## 六种成长路径示例

- **纸童·回火循环：** 归灰第一阶提高回收，第二阶返击，搭火星灯扩散；使用纸燕演化，围绕击杀位置安排下一次施放。
- **铃师·群债红网：** 红绳二阶收紧，游风一阶补位移；赤网让追近敌人留在链内，再用回音类遗物处理后排。
- **灯客·持续焚场：** 烬火三阶烧尽，墨契一阶延时印；走马灯沿场边移动，持续让高血目标进入引爆窗口。
- **傩面·镇印反击：** 镇印二阶招架，归灰一阶回收；护门迎正面弹阵，拿铜印裂纹把成功格挡转成伤害。
- **伞灵·游灰双返：** 游风强化返程，归灰增加自然香灰价值；借风把敌人推入返程路线，回收后再开技能。
- **墨吏·穿账留白：** 墨契延迟、红绳补远目标连接；重书留下一笔，自己退开引诱追击，再让第二笔结算。

每条路线都有便宜的第一阶入口、两件普通启动遗物、两件进阶联动件和一个较稀有终局件。构筑能够在缺少终局件时成立。

## 局外还愿簿

善缘在清房、首次任务和结局时获得，记录为账号本地进度：普通清房 1、精英 2、Boss 5。首通每位 Boss 额外 8，首次角色任务按阶段给予 5、10、15。重复击杀同一已记账敌人或重进已清房不给重复善缘。

还愿簿分四页：角色个人页、遗物发现页、区域故事页、训练与外观页。主要解锁新初始武器备选、遗物、支路与外观。全局便利项目包括自动拾钱范围、图鉴演示和训练靶设置；便利不改变战斗伤害或敌人血量。

角色个人任务三阶段分别给予一项外观、一项初始武器备选、一张结局页。掌握度只反映进度，不提供可无限叠加的永久攻防。新角色可以在已有内容池中完成完整一局。

## 池子管理与内容扩张

新增遗物同时标注路线、触发事件、叠加方式、触发预算、兼容武器和危险反馈。图鉴可查看已解锁物，单局选型页允许选择基础或扩展池；还愿庭的每日种子入口固定 `initial-v1` 池版本，以便离线比较同一局；每日结算不污染局外成长账本。

保存内容版本和 ID。删除或替换内容时迁移到明确替代件，保持技能和装备槽结构合法；不能把已拥有的奖励静默重抽。
