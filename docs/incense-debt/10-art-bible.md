# 美术设定与视觉规则

## 总体方向

架空中式庙会的怪诞纸世界：木版年画的粗墨轮廓、剪纸的层叠缺口、纸扎的折线和铜器的钝亮边。角色拥有大头短身、两三档明暗和稳定的面部特征。阴森来自空庙、缺名和旧账，亲近感来自小纸人的动作与市井物件。

## 色板与语义

| 名称 | 色值 | 用法 |
| --- | --- | --- |
| 朱砂 | #BC3C2F | 衣物、帘布、债线，避开大面积危险闪光 |
| 煤墨 | #242725 | 粗轮廓、阴影、字体和缝隙 |
| 纸白 | #E7D8B6 | 角色脸、纸缘、菜单纸页、关键高光 |
| 旧金 | #C39A51 | 铜器、奖励、焚债重击 |
| 灰玉 | #53675C | 地面、石墙、次要环境 |
| 香火橙 | #E9A34B | 友方圆火片、余烬与爆圈 |
| 敌弹玉青 | #75C5B2 | 敌方尖核子弹与边框 |

友方火区是橙金圆/曲线边，敌方印区有锯齿黑边、玉青尖角与预警圈，即使颜色接近也能靠形状区分。债链为细朱线加米白绳结；大面积红帘只放在外围。

## 视角、光照与线粗

固定近俯视：地面从上看，角色保留略正面的可读面孔，底部短影标定脚点。光源固定左上，阴影向右下。所有角色、道具、敌人与门保持相同倾角，武器图标可单独使用正侧面展示。

96像素角色外轮廓约2–3像素，内部线约1–2像素；高分辨率生成图按比例保留轮廓，再统一缩放。纸纹优先放大形体内与边缘，不能把脸、敌弹和余烬状态切碎。

## 三个区域

**纸灯巷：** 灰玉石地、残朱帘、折纸供物和旧灯架。轮廓轻、门形宽，初始地图较开阔。纹理只有少量纸屑与石缝，方便学习弹幕。

**铜钱库：** 深灰铜地、旧金管线、方形钱架和算盘构件。铜柱有固定硬边，可反弹表面使用金边与铆钉；不能反弹的纸柱使用纤维边。色调仍控制在同一朱墨纸金系统。

**无主神殿：** 大片米白断页、煤墨神龛、稀疏朱印与空白牌。舞台感更强，危险区出现前，地面的低亮印线先闭合。背景纸纹降低对比，最后阶段仍保留清楚的子弹外边。

## 主角、敌人、Boss 层级

主角面部亮、动作紧凑、主体在96像素显示时可认。纸童圆、铃师横向铃线、灯客细长、傩面方厚、伞灵宽伞、墨吏高帽长卷，六种剪影不依赖配色。

敌人用缺口、倒折、空洞和不对称形成“坏掉的愿”，主体面孔比主角更暗；预警时局部亮起。精英额外冠饰和绳结，Boss使用较大可动铜/纸部件，但命中边界始终有明确脚影或底框。

## 动画与特效

移动是折叠回弹，攻击是下压或甩线，受伤是纸角裂动，死亡是轮廓先散再落纸。方向包括下、左、右、上，横向可在保持道具手位一致时复用镜像。脸与关键装备在跑步中保持大小。

焚债的完整节奏为线绷紧、火点聚合、纸屑爆开、金灰回流。纸屑优先少量大块，持续不超过0.6秒。敌弹优先于粒子绘制，地面预警优先于地面装饰。低画质保留线、标记、预警和敌弹。

## UI 与文字

菜单以现代游戏布局组织还愿簿主题：深墨灰面板、纸白粗标题、朱砂主行动、旧金状态。角色肖像保留米白纸页；角色选择和奖励使用一致的卡片层级。界面采用 Noto Sans SC 500/700/800 字重，不使用细字重或将正文生成为图片。现代 UI 和原设计图的约束详见[视觉一致性约定](17-visual-contract.md)。

文字不烘焙进房间、道具或合同素材，数值与本地化由界面绘制。图标每件只保留一个主形，路线徽记靠外形区分。

## 美术验收

每次检查100%、实际游戏尺寸和灰度三种视图；六角色缩小后能认，敌弹不与地面合并，透明边缘不泛白，动画帧脚点不漂。概念板确认材质语言，正式素材仍要单独通过透明、锚点、动画和引擎运行检查。
