# 交互体验、HUD、输入与多端布局

## 一条完整体验链

标题 → 三个独立愿簿 → 主菜单 → 新局选角／继续／挑战／记录／设置。每页方向键选择、Enter 确认、Esc 返回，Tab／Shift+Tab 顺序切换；父页、焦点、滚动与替换存档确认详见 [菜单与键盘审计](22-menu-save-achievements.md)。选角只承担本次角色、初始器具与成就信息，局外系统通过主菜单进入。

战斗HUD保持中心空白。生命在左上、章节路径在顶部中央、纸钱与愿簿及暂停在右上；焚债状态靠近输入区，触控模式香火放在左上生命下方。只有升级、合同和Boss阶段等重要事件出现短提示。掉落先显示图标，交互时展开说明。选择和对话暂停战斗。字体、面板和实际截图基准见[视觉一致性约定](17-visual-contract.md)。

## 三端共通动作

| 动作 | PC 鼠键默认 | 手柄默认 | Android / iOS |
| --- | --- | --- | --- |
| 移动 | WASD | 左摇杆 | 左虚拟摇杆 |
| 瞄准 | 鼠标 | 右摇杆 | 右虚拟摇杆 |
| 方向瞄准/开火 | 方向键 ↑↓←→（按住即持续射击） | 左摇杆按键可选 | — |
| 主攻击 | 左键按住 | RT；可选右摇杆超过阈值即开火 | 右摇杆超过阈值即开火 |
| 焚债 | 右键 | RB | 右侧焚债按钮 |
| 身法 | Space | LT | 右侧身法按钮 |
| 交互 | E | A | 靠近后出现交互按钮 |
| 行路图 | Tab | 左摇杆按键可选 | 顶部地图图标 |
| 构筑/愿簿 | I | Back | 顶部愿簿图标 |
| 暂停/返回 | Esc | Menu / B | 右上暂停与系统返回 |

游戏动作可按设备重映射，键盘支持单键（含Shift/Ctrl）、鼠标支持左右中键与侧键，手柄支持按钮和轴方向；重复占用会交换。Esc保留为菜单取消入口，菜单确认与焦点导航继续使用系统默认映射。动作提示随实际绑定与当前设备更新。近战使用同一瞄准动作。技能按钮不会因角色增加，每角色演化只替换焚债行为。

方向键瞄准会覆盖鼠标瞄准并保留最后有效朝向，按住任一方向键同时触发主攻击；松开后立即解除方向键开火，不会让旧输入继续连射。Tab只打开只读行路图，Esc先停在圆角暂停页，I打开构筑页，三者都清空开火边沿且不推进战斗 tick。

## 触控细节

横屏，左摇杆可选固定/浮动，右摇杆独立捕获触点ID。摇杆默认死区0.18，开火阈值0.22；右摇杆归零后主攻击停止，保留最后有效瞄准方向用于焚债。手指移出摇杆区域不会立刻跳给另一按钮，抬起后才释放。

焚债与身法按键放在右摇杆上侧和内侧，默认至少56设备逻辑点的触控范围，间距至少8；Android下限48dp，iOS下限44pt。触控层独立于战场缩放，不能把世界坐标像素直接当成dp/pt。[Android官方触控尺寸](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)、[Apple游戏控制](https://developer.apple.com/design/human-interface-guidelines/game-controls)。

三个同时触点应支持移动、瞄准开火和技能/身法。技能可在移动中按下；技能施放后不抢走右摇杆触点。HUD布局可拖动、调透明度、调大小，支持左右手镜像。镜像只改变输入布局，房间和掉落种子相同。

辅助瞄准默认提供轻度角度吸附：瞄准向量的15度扇区中优先未被遮挡近目标；手动偏离可立即解除。自动瞄准作为可选模式，锁定保持0.25秒以避免跳目标；不取消敌人的预警与闪避要求。记录辅助设置用于复现实验。

## 安全区与屏幕比例

战场按1280×720基准进行完整显示。16:9等比缩放，较宽手机把额外边缘用于触控和纸纹边饰；敌人不能仅在宽屏上提早可见并可攻击。4:3平板保持完整房间并使用上下留白容纳辅助UI。

运行时读取真实显示安全区，按钮避开刘海、摄像头和Home指示条；旋转、折叠与分屏变化后重新布局。世界内容和输入UI分别换算坐标。[Godot DisplayServer安全区](https://docs.godotengine.org/en/stable/classes/class_displayserver.html#class-displayserver-method-get-display-safe-area)。

竖屏时先暂停并显示旋转提示，输入清零；旋回横屏后保留暂停，用户确认继续。Android返回键先关闭顶层页面，再打开暂停；不能直接丢掉单局。

## 选择面板与信息层级

奖励每次三选一，卡片首先展示名称、主图、行为短句和路线图标；数字与限制在展开详情。桌面端可直接按键盘数字行 `1`、`2`、`3`、`4` 提交对应候选，不要求先移动焦点或再按 Enter；不足四项时未显示的数字不产生动作。选中后给一段简短演示或方向箭头。触控与手柄仍保留焦点/确认路径。

合同卡必须同时显示奖励、代价、还愿金额、触发范围和风险点。强度不用稀有色替代惩罚说明。购买、替换装备和偿还操作都先给差额或库存预览，提交中按钮禁用。

暂停页保留继续、设置、回灯下和“本局记录”四项行动；本局记录以时间顺序列出本局从初始武器/技能到后续武器、技能演化、供物、行愿、债约、特殊房奖励与偿还的全部选择，并在右侧展示当前构筑摘要。记录随单局快照保存和恢复，旧存档缺少该字段时显示已有信息。构筑通过独立愿簿入口查看武器、技能、供物、成长、合同和组合册，清房后查看行路。行路图只读显示方向和已行节点，真正切房必须回到战场走进对应发光门。结算使用图标统计卡与同角色重开，不要求回到多层菜单。结算的受击/愿页入口展开十二次近期记录、复活/护甲细节与真实入账任务；本局构筑关闭后返回结算，不恢复已结束的战斗。

## 新手提示与可访问性

只在第一次相关事件出现一条短提示：挂余烬、绳链、能量不足、清房奖励、债约。训练场允许重播。战斗中没有长段说明，关键失败反馈用图案和短声音表达。

提供震屏强度、顿帧表现、闪光强度、粒子密度、动态性能档位、色觉友好、字幕/战斗文字大小、数字弹字、触觉、按键按住/切换、自动拾取范围和瞄准辅助选项。动态性能支持自动平衡、高画质和省电三档；自动档只在移动端依据连续帧耗时调整表现层，不改变规则、伤害或随机流。色觉模式加强形状边线；静音时重要攻击同时有图案提示。

在后台、失焦、系统对话框或触控取消事件中，输入清零并暂停；回前台要求主动确认。设置和菜单可用键盘/手柄操作，焦点以清楚的圆角边线标示。

线框图见 [PC布局](assets/wireframes/pc.svg) 和 [移动布局](assets/wireframes/mobile.svg)；它们说明布局与触点区，不代表已运行的游戏。
## 2026-10-04 运行记录

以下是更新前界面记录。当前字体、圆角、色板、图标与信息密度以2026-10-05的[最新视觉约定](17-visual-contract.md)为准。

早期界面使用 Noto Sans SC 500/700/800 与现代深灰、旧金、朱砂面板，细字重导入问题已修复。桌面奖励卡和移动单卡翻页分别布局；移动设置、选择与行路图加大触控范围，行路图支持纵向拖动。独立三指、镜像、安全区与投影后的摇杆方向有自动检查。系统返回和手柄 Start/B 关闭顶层/暂停，切后台清除输入并保存。可用设置包括声音、三路音量、触控显隐、镜像、鼠键/手柄重映射、触点编辑/大小/透明度、固定/浮动摇杆、死区、按住/切换攻击、瞄准辅助、触觉，以及震屏、受击闪光、顿帧、纸屑、色觉形状、数字、战斗文字、愿页字号和自动拾取范围。54项输入检查覆盖新增范围；原生GUI验证按键与字号录入、实际存档、滚动正文、方向保护及物理入口，画面扩展到38组。触控布局的绘制与捕获共用中心和半径；存档恢复会规范化按键码的数值类型。物理手柄、实际震动、手机旋转和交互仍需设备验收。

愿页和庭中短句可选标准、125%、150%；正文保持500字重并在固定区域滚动，标题与收起按钮保留层级。滚轮、触屏拖动、上下方向键与PageUp/PageDown均可翻读。拾取半径为标准、扩大25%、缩小50%，只作用于余烬和纸钱；局外拾钱加成照常先计算，治疗仍需靠近24逻辑单位，清房自动收齐不变。倍率保存进单局以供复现，重开与继续时读取当前操作偏好。

移动界面读取[原生窗口尺寸](https://docs.godotengine.org/en/stable/classes/class_displayserver.html#class-displayserver-method-window-get-size)，宽高比不超过1.05时显示同风格旋转提示、清空触点并暂停；达到1.20后解除遮罩，保留主动确认的暂停页。滞回阈值避免折叠/分屏抖动。桌面验收使用注入尺寸，不将它记作真实手机旋转。

触觉接口使用[Godot Input 官方说明](https://docs.godotengine.org/en/stable/classes/class_input.html#class-input-method-vibrate-handheld)。Android导出启用VIBRATE普通权限；没有网络权限。手机脉冲最长65ms；暂停停止新的请求并取消手柄震动，设备自身的震动设置仍可能阻止反馈。

普通房门以发光阈值、方向箭头和环形脉冲表示，已行门使用旧金，新门使用玉青；玩家必须朝门口移动并穿过阈值，才触发房间切换。进入新房会从相对门口出生，返回旧房保留原障碍、掉落和领取状态。断绳入口以同一门框的封闭、展开和已行三态表示。靠近检查时显示短弧进度，显露后出现“断绳入页”和明确按钮；按钮只辅助确认，走入入口仍是实际迁移。清房提示、门口图形与移动摇杆互不遮挡；手机清房只保留移动摇杆，收起无战斗作用的射击与技能触控图案。行路图省略未发现密室，允许查看可返回的已行节点；回访后不能重复领取奖励。

两阵房在章节栏下显示“第N / 2阵”，收灰窗口显示短句并播放警示，登场敌人有玉青圈和计时；预警结束后才成为有效战斗目标。这些提示使用既有纸白/旧金与700字重，不改变战场中央纹样。

2026-10-05新增“愿簿传递”：同源角色肖像与进度摘要位于上方，复制/导出、粘贴/导入两组行动并排，下方保留恢复和返回。预览只展示内容，确认后才整体换入；默认保留本机操作和声音，导入前备份可重启后恢复。进入新进度后清空输入并回当前愿簿的主菜单，续局仍需主动确认。系统文件选择器不可用时保留文字传递；手机软键盘与剪贴板继续列为设备验收。

本轮UI采用24圆角面板、完整圆形图标按钮、胶囊主行动、低饱和深灰与杏橙/玉青强调。57个工具图标取代重复长标签，战斗保留生命、香火进度、章节、钱与技能，中心战场留空。愿簿以实物图标网格和单条详情显示构筑；组合册追加三件供物进度与路线色；设置为四开关与六磁贴；还愿庭顶部增加每日种子图标入口，悬浮说明直接显示日期和固定池规则；暂停页新增本局成长记录入口，选择面板支持 PC 数字键 1—4 直接取卡；辅助说明点击信息按钮展开。正文使用资源圆体Medium/Bold授权子集，标题使用得意黑，稀有姓名回退Noto。最新Windows编译程序有90张原生图与75项GUI操作检查，含物理门口导航、组合册、灯摊试射/返回和本局记录；手机夹具采用放大圆形触点，真实设备验收单独保留。

角色详情由首页信息图标或锁定角色直接打开。初始武器、实际天赋、本职路线、当前个人任务及三种技能以两列圆角卡呈现；选择图标只切换说明，不改动单局。试演进入独立训练，余烬靶位已备好，动作使用实际技能规则；即使角色未留名，也不计任务、善缘或解锁。返回及重置为圆形图标，沿用当前技能；Escape/系统返回收起详情。新增软件检查注入触控事件并覆盖全部十八预设及存档保护，不冒充物理手机触控。

## 纯键盘闭环验收

本轮对标题、三槽、主菜单、选角、技能连续选择、四个数字快捷键、商店与试射、特殊房、供物替换、偿债、暂停记录、复盘、结局、存档导入及恢复使用原生键盘事件回归。菜单输入由独立焦点管理器处理，战斗方向键只在游玩时瞄准射击；松开后保持最后方向，实际移动鼠标才切回鼠标瞄准。长列表支持 PgUp／PgDn、Home／End，图标与完整选择说明可用 F1 查看。音量左右调整、文本框 Tab 离开、触点编辑 Enter 切换，均有可退出路径。

存档导入与菜单提示统一放在顶部，避免遮住选角底部的详情、成就、器具和开始按钮；紧凑布局使用原生矩形相交检查验证。
