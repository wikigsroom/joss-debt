# 菜单、存档槽与角色成就架构

本轮以《以撒的结合：重生／忏悔》的单人菜单为参照，实际检查《香火债》的原生控件、返回路径和键盘输入。上一版把存档卡片与主菜单混在一页，并把默认控件支持误写成“键盘闭环”；本轮纠正这两项结论。现代圆角、图标、资源圆体与得意黑继续沿用当前视觉规范。

## 差异审计

| 层级或行为 | 参照结构 | 本轮检查发现的差异 | 已落实的处理 |
| --- | --- | --- | --- |
| 标题 | 标题入口后选择存档 | 启动直接看到混合菜单 | 独立标题，Enter 开始 |
| 存档 | 三份存档独立选择，再进入对应主菜单 | 三张槽位卡与所有菜单平铺 | 独立愿簿页，左右键选槽、Enter 打开 |
| 主菜单 | 新局、继续、挑战、记录、选项分开 | 二列等权卡片，成就与庭院并列后缺少记录总入口 | 纵向新局／继续／挑战／记录／还愿庭／设置／离开 |
| 无可继续的存档 | Continue 不可用 | 缺少统一的禁用项导航规则 | 禁用继续，方向键和 Tab 自动跳过 |
| 新局 | 先选角色，再开始一局 | 角色页重复提供继续、庭院、设置、离开 | 选角页只保留返回、详情、角色成就、初始器具、开始 |
| 角色进度 | 选角时可看该角色完成标记 | 只有成就总数，初始器具与继续按钮还会重叠 | 展示四枚角色成就印记；底部尺寸按按钮高度排列 |
| 挑战 | 挑战规则入口独立，之后进入对应局 | 每日直接使用上一次选中的角色 | 挑战规则页 → 挑战选角 → 开始／替换确认 |
| 记录 | Stats 内整理 Secrets、Items、Endings 等；忏悔含 Bestiary | 图鉴藏在庭院，缺少独立记录层 | 记录内分成就、物品、怪物、结局、统计、旧愿 |
| 图鉴 | 已发现内容随存档保存 | 混合列表只能鼠标滚动 | 分供物／器具、恶愿／首领；焦点自动滚入可见范围，支持翻页 |
| 选项来源 | 主菜单和暂停都可进入 Options | 设置共享一个可被筛选覆盖的返回变量 | 每个页面记录自己的父页，从暂停进入就返回暂停 |
| 设置子页 | 子页先回选项 | 声音和致谢仍被当成 settings，Esc 会跨层 | 独立 audio_settings／credits，Esc 先返回设置 |
| 成就筛选 | 浏览不影响进入来源 | 筛选角色后会覆盖暂停来源 | 成就父页只在进入时记录，筛选与翻页不重写父页 |
| 暂停 | 继续与退出到菜单是独立行动 | 存下后再继续，旧退出按钮可能成为焦点 | 恢复存档明确聚焦继续；保存成功才返回菜单 |
| 开新局 | 明确放弃当前局 | 未完成的 checkpoint 可被静默覆盖 | 替换确认默认聚焦返回；取消不改存档 |
| 构筑与复盘 | 关闭返回打开它的层 | 从复盘打开构筑后直接跳结算 | 构筑 → 原复盘页 → 结算 → 主菜单 |
| 退出 | 明确退出，进行中局保留 | 顶部多处重复提供立即退出 | 主菜单统一退出确认；保存失败留在当前界面 |
| 键盘导航 | 方向键／确认／取消贯穿菜单 | 依赖默认焦点，重建后丢焦点，阅读控件难以退出 | 统一焦点管理、语义标识、逐页初始焦点、可见焦点环 |
| 攻击操作 | 四向射击可独立于移动 | 松开方向键后瞄准会被静止鼠标坐标改写 | WASD 移动，方向键射击；最后键盘方向保持到实际移动鼠标 |

参照资料：[角色完成标记](https://bindingofisaacrebirth.wiki.gg/wiki/Completion_Mark)、[主菜单与暂停内的选项](https://bindingofisaacrebirth.wiki.gg/wiki/Options)、[记录内查看结局](https://bindingofisaacrebirth.wiki.gg/wiki/Endings)。本表是层级与交互审计，没有在本机运行原作，也不把原作的完整玩法目录视为已经实现。

## 菜单状态机

```text
标题（splash）
└─ 三个愿簿（files）
   └─ 主菜单（title）
      ├─ 新局 → 选角 → 详情／初始器具／角色成就 → 替换确认（如有未完成局）→ 教学 → 房间
      ├─ 继续 → 暂停确认 → 房间
      ├─ 挑战 → 每日规则 → 挑战选角 → 确认／教学 → 每日房间
      ├─ 记录（stats）
      │  ├─ 成就 → 全部／角色筛选
      │  ├─ 物品 → 供物／器具 → 已发现条目详情
      │  ├─ 怪物 → 恶愿／首领 → 已发现条目详情
      │  ├─ 结局 → 已收藏结局 → 愿页阅读
      │  ├─ 统计 → 六名角色的正式还愿、胜利、个人页
      │  └─ 旧愿 → 庭院旧愿页 → 阅读
      ├─ 还愿庭 → 还愿／图鉴与训练／债约／器具／留名
      ├─ 设置 → 声音／按键／辅助／触控布局／愿簿传递／致谢
      └─ 离开 → 保存并退出确认

房间
├─ Tab 行路图 → Tab／Esc 收起
├─ I 构筑 → I／Esc 收起
├─ 成长／供物／技能演化 → 方向键 + Enter，或 1—4
├─ 商店 → 试射／购买／继续；Esc 从试射回原商店
├─ 献祭／判官／观音／事件／债约 → 选择／继续
├─ 愿簿已满 → 选择换出供物／取消
├─ 章末 → 偿债／下一章 → 技能演化
└─ Esc 暂停 → 继续／本局记录／成就／设置／保存回主菜单

胜利 → 必选结局 → 结算
失败 → 结算
结算 → 构筑／受击与愿页复盘 → 返回结算 → 主菜单／新局
```

Esc 每次返回一层。菜单中的 Tab 循环焦点，Shift+Tab 反向；游戏内 Tab 打开地图，地图内再按 Tab 收起。不通过地图按钮或直接修改房间编号跳层，房间移动必须穿过真实方向门。必选技能演化可以暂时暂停，最终结局停留在选择页；两者都不能用 Esc 跳过。用方向键、Enter 或对应数字完成选择即可继续。

## 存档模型

`SaveSession` 将 profile、checkpoint 与 backup 成对提交，`SaveSlots` 负责三槽索引与路径隔离。槽位 1 继续沿用 user://save_bundle 及旧 profile／saves 迁移路径，2／3 使用各自 slots/slot_N 目录。切换时读取该槽的独立默认设置，空槽不会继承上一槽的音量与键位。

| 内容 | 写入时机 | 保护 |
| --- | --- | --- |
| 角色、善缘、图鉴、个人页、成就、设置 | 清房、领取、解锁、设置提交 | 双代校验日志、内容版本保护 |
| 房间、随机流、敌群、弹道、构筑、成长历史 | 清房、领取、手动保存、后台／失焦 | 同一 journal 与 profile 成对保存 |
| 当前槽位 | 选择愿簿 | 索引提交成功后才重新绑定世界与 HUD |
| 导入前 profile 与 checkpoint | 确认导入 | 预览不提交；独立备份可恢复 |
| 未完成局的替换 | 新局确认 | 默认返回；取消不改变 checkpoint |

暂停回主菜单和退出都检查实际写入结果。愿簿传递提供纯键盘“复制 → 粘贴 → 预览 → 确认 → 恢复导入前”路线；桌面原生文件选择器仍可使用系统键盘导航，自动回归使用文字路线，不操作用户文件对话框。

## 角色成就规则

稳定清单 game/data/achievements.json：每名角色四项，共二十四项角色成就，另有八项账户成就。角色项对应本职高光、一次胜利、路线、三页个人愿簿。账户项记录首次／多次胜利、六人胜利、结局、首领、路线、供物和正式还愿次数。

成就由 MetaProgress.observe 增量更新，run.id 幂等入账；训练和每日不计正式成长。选角四枚印记读取这些持久化成就，筛选只改变视图。未完成项目保持隐藏描述，进度仍可阅读。它们是本作角色成就摘要，尚不是原作“每位角色 × 每名终局首领 × 普通／困难”的完成格。

## 操作契约

| 场景 | 纯键盘操作 |
| --- | --- |
| 所有普通菜单、网格、卡片 | ↑↓←→；Enter 或小键盘 Enter；Esc 返回；Tab／Shift+Tab 顺序导航 |
| 重建页面、筛选、调整开关 | 语义焦点保留；禁用项跳过；图标焦点在底部显示动作名 |
| 所有长列表／阅读页 | PgUp／PgDn 翻页、Home／End 到首尾；聚焦阅读区后上下滚动 |
| 完整技能／供物说明 | 焦点处 F1 详情；Esc 回到原选择与原焦点 |
| 音量 | 左右调整，上下切换混音项；Esc 保存并回设置 |
| 按键设置 | Enter 录入 → 按新键；Esc 取消录入，再按 Esc 回设置；菜单导航键不随战斗重映射失效 |
| 文本输入／存档粘贴 | 原生输入、Ctrl+A／Ctrl+V；Tab 离开文本框；Esc 返回 |
| 触控布局编辑 | 方向键微调触点、Enter 切换触点、Tab 离开编辑区 |
| 成长、技能、商店、特殊房 | 方向键 + Enter；1／2／3／4 直接选取；重复按住数字不重复领取 |
| 房间 | WASD 移动、方向键瞄准并射击、Space 身法、Q 技能、E 场景交互 |
| 地图／构筑／暂停 | Tab 地图、I 构筑、Esc 暂停；各自原键可收起地图与构筑 |
| 商店试射／角色试演 | 原战斗按键；Esc 回原商店／角色详情 |

焦点记忆按页面及“本局 ID／房间／选择类型”隔离，同房间刷新保留位置，新房间不会继承上一房的继续或换一页焦点。操作输入在模态层被消费，不同时转成射击；回战斗会清除界面焦点和按住攻击的残留。

仍保留的结构差异：本作有还愿庭与横向成长、六名角色、每日规则和可读结局；尚未实现原作贪婪／普通与困难模式、完整固定挑战目录、里角色、Mod 与联机菜单。这些入口不会用空按钮占位。现代图标与圆角 UI 继续采用本作视觉，不照搬原作字形和素材。

原生键盘行为证据见 reports/platforms/windows/keyboard/keyboard-flow.json；普通原生 GUI 与截图见 reports/platforms/windows/native-render.json；可重跑 python tools/runtime/run_keyboard_qa.py --packaged。回归会通过真实 InputEventKey 激活控件，测试驱动不调用 grab_focus、按钮回调或鼠标事件；可选房间用固定场景准备，不等同真人三章平衡验收。

十一重扩展加入选角页的十二位种子入口：键盘可进入输入框、确认或重抽，保留前导零；开始本局后清除输入草稿，后续新局重新生成。暂停页可以查看并复制当前种子。过场使用 Enter 推进、Esc 暂停，支持收起播片；保存继续恢复已读页数，F1 说明关闭后返回原过场。

Tab 行路图现在分为基础数值、可滚动房间图、完整供物与词条三列，另含全部本局选择历史。方向键与 PageUp／PageDown 滚动当前区域，Ctrl+Tab 切换图内可操作区域，Tab 或 Esc 收起地图。最终层40间房、32条构筑与100条历史通过原生键盘夹具检查。扩展证据保存于 reports/platforms/windows/expansion/expansion-native.json，完整战斗通关另见 reports/runtime/expanded-full-run.json。
