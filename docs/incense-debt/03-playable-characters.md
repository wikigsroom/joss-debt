# 多可玩角色体系

六名主角都拥有主攻击、身法和一个焚债按钮。专属技能是焚债的不同形态；两种演化替换该按钮的行为。角色天赋固定，武器和通用遗物开放混搭。完整参数及 ID 见内容数据库。

## 纸童：从点燃到成串回收

定位：容易上手的完整循环角色。基础焚债“撒灰”引爆附近的余烬目标。演化“纸燕”把爆发转为会寻找已标记目标的灰燕；“爆竹”把爆发集中到四向通道，适合主动拉直敌群。

首房教学要求用两次射击给两个目标挂余烬，然后焚债。纸童的回收天赋让玩家立即理解“更好的击杀安排可以带来下一次技能”。其强项是频繁小爆发，处理远距离盾阵需要换枪或红绳补强。

造型：大米白纸面具、短朱袍、青铜香炉；走路略有纸张折动，受伤裂开边角，焚债时香炉短促下压。解锁成长后获得纸衣边样与香炉形状，命中体积保持相同。

## 铃师：把目标关系变成武器

定位：高机动控场。基础“铃断”优先沿一组债链依次引爆；“赤网”把债链短暂收紧以限制普通敌人的移动；“回音”对本次固定目标集合进行第二段低伤脉冲，第二段不会再次触发额外遗物。

铃弹能给近邻追加轻标记，适合穿过敌群边缘组织连接。失误代价是较低心火，Boss 的束缚抵抗阻止无限控场。推荐也可转归灰，在密集战房高频回收。

造型：菱形面具、双侧红绳圈、左右铃。铃的开合体现射击节奏；红线与角色动作只在连接变化时突出，避免常驻高亮覆盖地面。

## 灯客：控制引燃与烧尽的时机

定位：持续灼烧与阵地爆发。基础“灯宴”焚债后留下短时火区；“烛龙”沿窄长线集中引爆；“走马灯”让火区随玩家移动，需要贴近敌群边缘控制位置。

灼烧只给自然击杀正常奖励；由技能火区制造的余烬带同一事件来源，不能反复自触发。灯客先烧血较高的目标，再引爆低血目标，能把范围收益最大化。远距离快敌与移动强的 Boss 会检验玩家走位。

造型：灯笼头、黑红长外套、提灯杆；灯心亮度表达香火，颜色以火焰形状和亮暗共同区分。无技能能量时仍保留明显面部轮廓。

## 傩面：正面争取一个稳定爆发窗口

定位：近距、反击、较高容错。基础“镇印”在施放初段提供短时正面招架，再引爆近身目标；“护门”延长方向性阻挡、缩小爆发覆盖；“破阵”强化击退与冲阵破盾。

使用镇门印时要靠前摇判断出手。正面招架只处理可格挡子弹，背面伤害与地面印区需要闪避。控制稳定，移动较慢，在跑图与追逐战中需要游风支撑。

造型：大木面具、玉灰短披风、方形铜印锤。动作使用短促落地感，受伤与格挡使用不同的纸裂/铜鸣声音和图案。

## 伞灵：利用回收路线维持战斗流动

定位：高速移动、回旋弹、香灰循环。基础“回伞”扩大回收与焚债覆盖；“雨帐”把爆发拆为短时有节奏的落灰攻击；“借风”轻推普通目标，并改变回旋弹的进出路径。

碎骨伞返程可再次命中，但同一弹在同一阶段最多命中一个敌人一次。角色脆弱，拾灰路线本身就是走位问题；归灰可以降低空转，红绳可以补范围爆发。

造型：宽红伞、小纸灵体、飘带。伞的画面轮廓大于命中圆，伤害判定以伞下纸灵为准；设置和训练场显示判定中心。

## 墨吏：把一条线上的敌人一笔勾销

定位：穿透、延迟、精确目标顺序。基础“勾销”在当前瞄准线引爆带余烬目标；“飞白”拓展为三条窄线，以覆盖换单点强度；“重书”保留一条固定墨线，一秒后低伤重演，重演不派生新遗物事件。

墨吏挂标记的保留时间更长，允许先建立多个目标再选角度。敌阵散开或贴身围攻时需要更强的身法与控场。该角色可用火灯等范围武器，依然保留延长余烬的天赋。

造型：矩形纸帽、黑米白长衫、粗笔和空白账卷。墨线最初细且低亮，生效前以短划边框提示；敌人的延迟墨印使用玉青尖形边界。

## 平衡与解锁规则

所有角色基础身法拥有相同的无敌时间与冷却，显示轮廓不决定命中体积。角色难度从纸童、傩面逐渐延伸到铃师、灯客、伞灵、墨吏；“易用”与“上限”在选角页用描述而非误导性的强度星级表达。

每角色个人页有三阶段任务：掌握本职动作、完成一条跨路构筑、击败最终 Boss。奖励以外观、台词、初始武器备选和训练演示为主。初始武器备选不叠加属性，开局只携带一种主武器。
