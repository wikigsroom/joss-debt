# 声音、配乐与叙事交互

## 听觉语言

纸是轻脆的折、点、裂；铜是短而钝的敲击；火是低频起燃与干燥爆开；绳是紧拉后的轻弹；灰是细粒回流。攻击声音按这些材质组织，主角与敌人使用不同音高区间。

自然射击不持续盖住敌人前摇。焚债只在重要爆发使用低频重击；同时击杀多敌时组合成一次主体纸爆与有限补声，避免每只敌人叠出刺耳峰值。

## 必备音效

主攻发射、纸命中、铜命中、挂余烬、债链形成/绷紧、焚债、收灰、身法、招架、玩家受伤、普通死亡、Boss预警、奖励、签约、偿还和菜单，共十六组。每组准备二至四个短变体，音高变化限制在小范围。

同组声音并发上限四，优先级依次为玩家受伤/Boss预警、招架/焚债、主攻、普通击杀、环境。敌方大动作拥有独特预警短音，在静音设置下也有同步视觉提示。

音效为48kHz、16bit、单声道PCM WAV；配乐母版同为48kHz PCM，正式包使用单声道Vorbis压缩。声音由本项目原创合成并导入，音乐完整帧长、拍速、小节数与循环点登记。混音检查源素材和真实播放器输出，不以峰值拉满制造打击感。

## 配乐六场景

| 场景 | 仪器与节奏 | 动态变化 |
| --- | --- | --- |
| 还愿庭 | 木鱼式轻拍、拨弦、少量风铃 | 无战斗层，空出对白 |
| 纸灯巷 | 轻鼓、纸擦与短笛片段 | 入战加入鼓点，清房恢复疏松 |
| 铜钱库 | 低拨弦、铜片、算珠节拍 | 精英提高节拍层与低频 |
| 无主神殿 | 长音、断续鼓、空场混响 | 护印与开放核心使用不同层 |
| Boss | 明确拍点、铜鸣、厚纸鼓 | 转阶段停止一拍，配预警 |
| 结局 | 回愿庭主题变奏 | 三结局使用不同尾句 |

每个区域、Boss 和结局拥有独立的32小节主题；献灯、判官、观音、商店等非战斗房沿用当前区域底层，但切入对应的静谧身份层；破阵房沿用区域底层并直接提升张力层，三轮波次之间保留一拍预警空隙。特殊房确认成功播放一次契约/钟鸣提示，战斗房的节奏层不会因为打开地图或暂停而重新起拍。

音量设置分主音量、音乐、音效和对白；暂停时低通/降音量并保留菜单确认声。后台完全暂停音频，回前台先在暂停页恢复。

## 叙事触发

开场、首次连债、首次签约、首次还愿、Boss首次败退、三幕揭示和结局具有固定触发ID。触发记录写入存档，重复跑图使用短句版本；长版本可在图鉴查看。

战斗中只出现一句短反应，位置靠上且不挡危险提示；字幕可关闭角色反应但保留关键系统提示。完整对白只在安全房与阶段清弹后的短暂停留中播放，可跳过。

角色口吻彼此区分：纸童好奇、铃师嘴硬、灯客简短、傩面朴实、伞灵轻快、墨吏冷静讽刺。剧情以纸页、NPC回应和玩家已经做过的交易推进，避免长篇解释挤占战斗。

## 制作状态

音频清单先登记待制作与来源，原型可用程序合成的材质测试音校准节奏；`engine_verified`表示原生资源与内部混音验证，设备扬声器、耳机与真人听测单独登记。图片生成通道只用于美术图像，声音采用独立制作流程。
## 2026-10-06 运行记录

实际声音共112份：29个音效组各三变体的87份PCM WAV，以及九套完整32小节主题的25份Vorbis分层。每套主题长约67–116秒，分为陈述、回应、发展、留白、抬升、再回应、再现、回归八段，保留木、铜、纸与少量气声的听觉材料；三区域与首领另各有一条低音量、滤波、可循环CC0环境纹理，来源与处理链见[音频来源审计](reports/runtime/audio-source-research.json)。联网检索只筛选CC0环境和风格参考，前景BGM不复用外部旋律，由本地可复现编曲器生成。音效矩阵、采样率、变体数量和来源哈希由[音频矩阵验收](reports/runtime/audio-design-verification.json)锁定。三种结局保留不同尾句。旧短循环和新PCM母版留在生产目录，正式包不附带这些母版；外部CC0原文件只留在生产参考目录，不作为前景音乐。

三区域与首领使用原生AudioStreamSynchronized同时播放底层、节奏、张力和应答层，共用完整循环与拍速，切层不会重新播放主旋律。探索只留底层，入战在下一小节加入节奏；三目标连债、多目标焚债、精英、低心火或首领后阶段请求张力层。连债形成事件会按实际链接数延长短暂抬升，大链同时触发一次低音量铜铃回响；爆发事件保留短尾音，多目标爆发仍拥有更长的音乐回应。清房后退出战斗层。波次和首领阶段转换在下一拍留出一拍空间，危险预警和受伤另临时降低配乐音量。场景之间仍有350ms交叉淡化。

普通菜单暂停将音乐降至32%，保留拍点并让菜单声可听；窗口失焦和系统后台则冻结真实样本并停止现有音效。后台期间切场景不能重新开声，回前台保持游戏暂停，需要用户确认继续。静音覆盖新旧主题两边及当前音效。总体、音乐、音效音量分别保存；当前没有配音和对白音量滑块，叙事十四页可回看。

101项配乐与战斗声音回归检查覆盖下一小节变化、连债规模响应、爆发尾音、一拍留白、完整循环、原生资源长度、后台与静音，以及完整战斗快照不受音乐观察影响；其中逐条读取目录中的十六种武器模式，核对攻击层、命中层与轻伤/重伤/债伤受击层均有明确声音。Windows真实混音总线有22项检查和六段内部PCM录音；把录音与四条原创分层及一条滤波环境纹理按样本对齐拟合，核对实际节奏/张力/纹理比例、暂停衰减、接缝续播和静音，而非只读取控制器状态。录音不使用麦克风。证据见[规则与原生资源](reports/runtime/adaptive-music-tests.json)、[最新程序混音](reports/platforms/windows/audio/native-audio.json)与[生产记录](reports/runtime/music-production.json)。设备扬声器/耳机、人类长局听测和重复感仍待验收。
